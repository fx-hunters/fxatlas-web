## 변경 사유 (Why)
- 피그마 디자인 프로토타입(https://wise-lyric-41826757.figma.site/)과 리브랜딩('Divurve') 지침을 바탕으로 전사 웹 서비스의 핵심 셸(사이드바, 헤더, 모바일 내비게이션, 푸터)과 홈 대시보드 화면을 첫 번째 슬라이스로 구축하기 위함.
- 데스크톱(1024px+), 태블릿(768px~), 모바일(320px~) 등 다양한 뷰포트에서 깨지지 않는 반응형 UI 및 라이트/다크 테마 토큰 시스템을 완비하기 위함.

## 변경 내용 (What)
- **디자인 토큰 정립 (`src/styles/tokens.css`, `src/styles/layout.css`)**:
  - CSS `:root` 변수 기반 다크/라이트 모드, 통화 색상(USD/JPY/EUR), 상태 색상(정상/주의/위험) 및 레이아웃 규격 정의.
- **반응형 공통 레이아웃 컴포넌트 (`src/components/layout/`)**:
  - `Sidebar`: 데스크톱 전용 좌측 사이드바, `DIVURVE` 브랜딩, 탭 메뉴, 데모/테마 토글 버튼.
  - `Header`: 상단 스티키 헤더, 현재 화면 타이틀, 테마 전환, 알림, 마이페이지 바로가기.
  - `MobileNav`: 모바일 화면(<768px) 전용 하단 고정 터치 내비게이션 바.
  - `Footer`: 하단 면책 문구 고정 바.
- **공용 UI 컴포넌트 (`src/components/common/`)**:
  - `Icon`: 17종의 SVG 아이콘을 지원하는 경량 아이콘 컴포넌트.
  - `Card`: 타이틀/액션/하이라이트 스타일을 제공하는 공용 카드.
  - `Badge`: 5가지 상태별 variant를 지원하는 뱃지.
  - `ProgressBar`: 0~100% 비율을 시각화하고 ARIA 접근성을 준수하는 프로그레스 바.
  - `DonutChart`: SVG 기반의 외화 비중 도넛 차트.
  - `SparklineChart`: SVG 영역 그라디언트를 지원하는 환율 추이 스파크라인 차트.
- **홈 화면 (`src/screens/home/`)**:
  - `TodayActionCard`: 이번 주 확보액($580/₩798,000), 마감일 D-3, 확보율, 회차 완료 기록 버튼.
  - `FxHoldingCard`: 내 외화 현황 도넛 차트, 통화별 비중 바(USD/JPY/EUR), 1% 민감도 지표.
  - `AttentionBanner`: JPY 임박 이벤트 등 주의 필요 경고 알림 및 플래너 바로가기.
  - `MarketSummaryCard`: USD/KRW 실시간 환율 및 밴드 범위, 스파크라인 차트.
  - `WeeklyComparisonCard`: 지난주 대비 확보율(+12.5%), 평가액(+₩312,000), USD 집중도(+2.1%p) 변동 지표.
  - `HomeEmptyView`: 외화 목표가 없을 때의 빈 상태 안내 화면.
  - `useHomeDashboard`: 상태 분리(discriminated union) 및 데모 모드 지원 훅.
- **전체 탭 연동 (`src/app/app.tsx`)**:
  - 홈, 환전 플래너, 내 자산, 환율 범위, 마이페이지, 연결 확인 탭 간의 라우팅 연결.

## 영향 / 리스크
- 기존의 연결 확인(`ConnectivityCheckPanel`) 테스트 페이지는 내비게이션 탭의 '연결 확인' 메뉴로 계속 접근 가능합니다.
- 순수 CSS 변수 및 경량 SVG 기반으로 구성되어 번들 사이즈가 가볍고 렌더링 성능이 우수합니다.
